
# A Spatio-Temporal Deep Learning Framework for Context-Aware Retail Sales Forecasting

## Project Description
This project is an AI-powered retail sales forecasting application that analyzes historical sales data and predicts future sales using machine learning.

## Technologies Used
- Python
- Flask
- XGBoost
- Pandas
- NumPy
- HTML
- CSS
- JavaScript
- Generative AI

## Features
- Retail sales analysis
- Future sales forecasting
- Interactive dashboard
- Revenue visualization
- AI-powered insights and recommendations

## Model
XGBoost is used as the selected forecasting model based on its lower Mean Absolute Error (MAE).

## How to Run Locally
1. Install dependencies:
   pip install -r requirements.txt

2. Start the application:
   python app.py

3. Open the local URL displayed in the terminal.
